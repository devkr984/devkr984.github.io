PHP 업그레이드

PHP 버전 업그레이드와 보안 패치, 왜 미루면 안 될까요?

P PHP.LAB 개발팀 · 2026.10.23 · 6분 분량

"지금 사이트가 잘 열리는데, PHP 버전을 꼭 올려야 하나요?"라는 질문을 자주 받습니다. 결과만 보면 문제가 없어 보이지만, 실제로는 보안의 관점에서 전혀 다른 이야기입니다.

PHP는 버전마다 정해진 지원 기간이 있고, 이 기간이 끝나면 새로운 취약점이 발견되어도 더 이상 보안 패치가 제공되지 않습니다. 이번 글에서는 PHP 보안 패치가 왜 중요한지, 내 사이트의 버전을 어떻게 확인하는지, 안전하게 업그레이드하는 절차까지 정리했습니다.

1. PHP 보안 패치, 정확히 무슨 의미인가요?

PHP는 공식적으로 각 버전마다 두 단계의 지원 기간을 운영합니다.

  • 활성 지원(Active Support) — 버그 수정과 보안 패치가 모두 제공되는 기간
  • 보안 지원(Security Support) — 심각한 보안 취약점에 대한 패치만 제공되는 기간

이 두 기간이 모두 끝나면 해당 버전은 지원 종료(EOL, End of Life) 상태가 됩니다. EOL 버전은 아무리 치명적인 취약점이 발견되어도 공식적으로 패치가 제공되지 않습니다. 즉, 알려진 취약점이 그대로 방치되는 것입니다.

2. 지원 종료 버전을 계속 사용하면 생기는 문제

단순히 "오래됐다"는 것이 문제가 아닙니다. 실제 운영 현장에서 자주 발견되는 위험은 다음과 같습니다.

  • 이미 공개된 취약점 정보를 이용한 자동화 해킹 시도 증가
  • 관리자가 인지하지 못한 사이 악성 스크립트나 백도어 삽입
  • 최신 프레임워크·라이브러리·플러그인과의 호환성 문제
  • 구버전 전용 공격 기법이 공개되어 공격 난이도가 낮아짐
  • 호스팅사의 PHP 버전 강제 종료 시 사전 대응 없이 사이트 다운

특히 공개 게시판, 회원제 사이트처럼 외부 입력을 처리하는 사이트는 지원 종료 버전에서 발견된 취약점이 공격에 바로 활용될 수 있어 위험이 더 큽니다.

3. 내 사이트의 PHP 버전은 어떻게 확인하나요?

개발자가 아니어도 다음 방법으로 현재 버전을 확인할 수 있습니다.

  • 호스팅사 관리자 패널의 "서버 정보" 또는 "PHP 버전 설정" 메뉴 확인
  • 워드프레스의 경우 관리자 대시보드 > 도구 > 사이트 상태에서 확인
  • FTP로 <?php phpinfo(); ?> 코드가 담긴 파일을 업로드해 브라우저로 접속해 확인

정확한 버전별 지원 현황은 PHP 공식 홈페이지의 지원 버전 안내 페이지에서 수시로 바뀌므로, 현재 사용 중인 버전이 활성 지원 또는 보안 지원 기간 내에 있는지 주기적으로 확인하는 것이 좋습니다.

4. 안전하게 업그레이드하는 절차

PHP 버전을 올리는 작업은 서버 설정 한 줄만 바꾸는 문제가 아닙니다. 기존 코드가 새 버전과 호환되는지 먼저 확인하는 과정이 반드시 필요합니다.

1단계. 현재 환경 진단

현재 PHP 버전, 사용 중인 프레임워크·플러그인, 외부 라이브러리 목록을 정리하고 업그레이드 대상 버전을 정합니다.

2단계. 코드 호환성 점검

신규 버전에서 제거되었거나 동작이 바뀐 함수·문법을 전체 코드에서 스캔하고, 수정이 필요한 범위를 파악합니다.

3단계. 테스트 환경에서 사전 검증

운영 서버와 분리된 테스트 환경에서 버전을 올리고, 로그인·결제·게시판 등 핵심 기능을 하나씩 검증합니다.

4단계. 백업 후 무중단 전환

전환 전 전체 소스와 데이터베이스를 백업하고, 검증이 끝난 환경으로 트래픽을 옮겨 서비스 중단 없이 적용합니다.

5단계. 전환 후 모니터링

전환 직후에는 에러 로그와 주요 기능을 집중적으로 모니터링해 예상치 못한 문제를 빠르게 발견하고 대응합니다.

5. 업그레이드 이후에도 보안 관리는 계속되어야 합니다

PHP 버전을 최신으로 올렸다고 해서 보안 문제가 영구히 해결되는 것은 아닙니다. 새로운 취약점은 꾸준히 발견되고, 이에 대응하는 패치도 주기적으로 배포됩니다.

따라서 업그레이드 이후에도 보안 패치 적용 여부를 지속적으로 점검하고, 백업과 장애 대응 체계를 함께 운영하는 것이 중요합니다. 이러한 정기 관리는 웹사이트 유지보수 서비스를 통해 맡기실 수 있으며, 워드프레스 기반 사이트라면 워드프레스 유지보수 서비스에서 코어·플러그인 업데이트까지 함께 관리해 드립니다.

마무리

PHP 보안 패치는 "언젠가 해도 되는 일"이 아니라 사이트가 공격받기 전에 끝내야 하는 작업입니다. 지금 운영 중인 사이트의 PHP 버전이 지원 종료 상태이거나 확실하지 않다면, 늦기 전에 점검을 받아보시길 권장합니다.
